Let Claude play your music.

Ask for a playlist. Get a real one, playing in Apple Music.

Download for macOS

Free · Apple Silicon · notarized by Apple · no terminal, no account, no API key

Things you can ask for

  • playlistsBuild me a dinner party playlist from albums I already own.
  • discoverySomething like Khruangbin, but faster.
  • your libraryWhat have I added this month that I haven't listened to?
  • playbackPlay the album that defined 90s hip-hop.

What it doesn't need

  • No accountNothing to sign up for, and no password to hand over. Apple's own MusicKit handles permission with a single prompt.
  • Nothing storedNo API key, no token, no cookie. There is no credential to keep, so none is kept on your Mac.
  • No terminalDownload, drag it to Applications, double-click once. The first window sets up the rest.
  • No developer accountOther Apple Music tools ask for a paid Apple Developer key. This one doesn't.

Questions

Which Macs does it work on?

macOS 14 (Sonoma) or later, on Apple Silicon. You need the Music app, signed into Apple Music.

Do I need an Apple Music subscription?

For your own library, playlists and playback, no. For playing or adding tracks from the Apple Music catalogue, yes — that's Apple's rule, not this app's.

Does it work on Windows or Linux?

No. It controls the Music app on macOS. Upstream supports Windows and Linux if you need them.

Which apps can use it?

Claude Desktop, Claude Code, Cursor, Windsurf, Codex and VS Code. The first-run window finds the ones you have and sets them up.

Is this made by Apple?

No. It's an independent, unofficial project, not affiliated with or endorsed by Apple. "Apple Music" and "MusicKit" are Apple's trademarks.

Can I see how it works?

Yes — all of it. The source is on GitHub, along with what permissions it asks for and why, an honest comparison with the alternatives, and checksums for every download.
